# 技术支持与相关格式

SoundFont 不是孤立的技术——它属于一个更大的采样音色生态。理解它与 VST、SFZ 等技术的关系，能帮你选对工具。

## 与 VST 的关系

VST（Virtual Studio Technology）是 Steinberg 于 1996 年推出的插件标准，允许第三方软件乐器（VSTi）和效果器运行在 DAW 内部。它是一种接口规范，本身不包含任何声音数据。

SoundFont 和 VST 不是竞争关系，而是不同层级的东西。SoundFont 是声音数据（录音采样打包成的文件），VST 是播放这些数据的软件接口。要播放一个 SoundFont，你需要一个采样器插件——而这类插件通常就是以 VST 形式存在的。

典型的工作流是：在 DAW 里加载一个 VST 采样器（如 sforzando、Zampler、Polyphone），然后把 .sf2 文件喂给它，它就能把 SoundFont 里的音色当作普通 VST 乐器来演奏。所以 SoundFont 可以被视为 VST 乐器的一种"音色来源"。

## SFZ 格式

SFZ 是 Plogue 公司（sforzando 的开发者）推出的纯文本音色格式。它与 SF2 的核心区别在于文件组织方式：SF2 是一个自包含的二进制文件，把采样数据和乐器定义全部打包在一起；SFZ 则是一个纯文本文件，里面写着乐器定义指令（opcode），再引用外部的 .wav 采样文件。

SFZ 的文本特性让它可以用任何编辑器打开修改，而且支持远比 SF2 丰富的映射控制——包括 round-robin（轮替采样）、key switch（按键切换音色）、CC 控制的表情参数等。SF2 主要只支持按键范围和力度范围的映射。两者可以通过 Polyphone 或 sforzando 互相转换。

## 主流播放器与引擎

播放 SoundFont 需要合成器引擎。目前主流的引擎有几种。

FluidSynth 是基于 SoundFont 2 规范的跨平台实时软件合成器，支持 Linux、macOS 和 Windows，完整支持 SF2 和 SF3（压缩格式），也支持 SoundFont 2.01 规范里的 modulator（调制器）。它是开源项目，被大量 MIDI 软件作为后端使用。

BASSMIDI 是 un4seen.com 开发的音频库，主要面向 Windows，音质出色，但对 SF3 压缩格式的支持有限，而且不完全支持 SoundFont 2.01 引入的全部 modulator。基于 BASSMIDI 的常见前端有 VirtualMIDISynth 和 Falcosoft Soundfont Midi Player。

SpessaSynth 是本项目使用的引擎，由开发者 spessasus 用纯 TypeScript 编写，运行在浏览器里，基于 AudioWorklet 实现实时合成。它支持 SF2 和 SF3，不依赖 SharedArrayBuffer 或 COEP 头，适合 Web 应用场景。

sforzando 是 Plogue 开发的免费 SFZ 播放器（VST/AU/AAX 插件 + 独立程序），是 SFZ 格式的参考实现。它也能导入 SF2 文件并导出为 SFZ。

## 版本演进

SoundFont 规范经历过几个版本。1991 年 E-mu Systems 和 Creative Labs 发布的 2.01 版是最基础也最广泛使用的规范，定义了 RIFF 文件结构和三层音色模型（采样/乐器/预设）。后来的 2.04 版增加了 24-bit 采样数据支持（原始只支持 16-bit），并与 2.01 双向兼容。SF3 是 MuseScore 推广的扩展，在 SF2 结构基础上把采样数据用 Ogg Vorbis 压缩，大幅缩小体积。
