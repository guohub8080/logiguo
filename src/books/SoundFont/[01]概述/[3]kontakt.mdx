# 与 Kontakt 的关系

提到采样器，绕不开 Native Instruments 的 Kontakt。它是当今专业音乐制作领域占有率最高的采样器平台，但它的定位和 SoundFont 完全不同。

## Kontakt 是什么

Kontakt 是 Native Instruments（NI）开发的软件采样器，以 VST/AU/AAX 插件形式运行在 DAW 里。它的音色库文件格式是 .nki（Kontakt Instrument），采样数据通常打包在 .nkx 或 .nks 压缩归档里。

和 SoundFont 的根本区别在于：SoundFont 是一个开放的声音数据格式，任何人都能读写；Kontakt 是一个商业软件，它的音色库大部分是加密的，只能用 Kontakt 自己打开。Kontakt 能做的事远比 SoundFont 多——内置效果器、高级调制路由、时间拉伸、颗粒合成、图形界面构建器，以及最重要的 KSP（Kontakt Script Processor）脚本系统，可以编程控制音色的演奏行为。

## 能力对比

SoundFont 的设计目标是"把录音采样按音高和力度映射到键盘上"，本质上是一个静态的采样回放容器。它有基本的 ADSR 包络、简单的 LFO 和调制器，但没有脚本、没有 round-robin（轮替采样，避免连续敲击同一个采样听起来机械）、没有按键切换articulation。

Kontakt 在这些方面都远超 SoundFont。一个 Kontakt 钢琴音色可以根据按键力度切换 10 层不同的采样，根据 CC 控制器切换延音踏板的共鸣模型，甚至根据演奏速度自动切换连奏和断奏的采样组——这些在 SF2 里基本做不到。

但 SoundFont 有自己的优势：格式开放、文件自包含、体积小、兼容性广。对于不需要复杂演奏控制的场景（乐理演示、MIDI 播放、复古游戏音色），SoundFont 完全够用，而且不用花几百美元买 Kontakt。

## 格式转换

两者之间可以互相转换，但有条件。

从 SF2 转 Kontakt（.nki）相对容易。旧版 Kontakt 可以直接在 Files Browser 里导入 SF2（需要勾选"Show Foreign Formats"），导入后另存为 .nki 即可。新版 Kontakt 移除了原生的 SF2 导入，需要第三方工具，比如 Extreme Sample Converter、Chickensys Translator，或开源的 ConvertWithMoss。

从 Kontakt 转 SF2 要难得多。只有未加密的 .nki 文件才能转换；使用 .nkx/.nks 加密归档的商业音色库无法直接转换。加密的音色库只能通过"演奏后重新采样"的方式间接转换，但这样会产生二代采样，音质有损。转换工具同样推荐 ConvertWithMoss 或 Extreme Sample Converter，转换后通常还要用 Polyphone 清理和修补映射关系。

## 什么时候选哪个

如果你做专业音乐制作，需要逼真的演奏表情、丰富的 articulation、商业级音色库——Kontakt 是行业标准，虽然有学习成本和价格门槛。

如果你做乐理工具、Web 应用、MIDI 播放器，或者只是想要轻量级的音色回放——SoundFont（配合 FluidSynth、SpessaSynth 等引擎）是更务实的选择。开放、免费、跨平台，这正是 Guookcase 选择它的原因。
