# NoteText 音符文本

<NoteTextDemo />

`NoteText` 和 `BlankNoteText` 是用于显示音符文本的组件，基于 Emotion CSS-in-JS 渲染，支持升降号符号（SVG）的自动显示。

## 组件

### NoteText

显示一个完整的音符，包含音名 + 升降号符号。

```tsx
import NoteText from "@music-comps/NoteText";

<NoteText step="C" alter={1} fontSize={24} />
// 显示 C#
```

### BlankNoteText

显示占位符文本，用于表示未知/待填音符。

```tsx
import BlankNoteText from "@music-comps/NoteText/BlankNoteText";

<BlankNoteText blankString="?" fontSize={24} />
```

## Props — NoteText

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `step` | `string` | — | 音名：C D E F G A B |
| `alter` | `number` | — | 变化音：-2(bb), -1(b), 0(♮), 1(#), 2(×) |
| `fontSize` | `number` | `14` | 字号 (px) |
| `isNatural` | `boolean` | `false` | 是否显示还原号（alter=0 时） |
| `color` | `string` | `gray800` | 文本和符号颜色 |

## Props — BlankNoteText

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `blankString` | `string` | `"?"` | 占位符文本 |
| `fontSize` | `number` | `14` | 字号 (px) |
| `color` | `string` | `gray800` | 文本颜色 |

## 升降号显示规则

`NoteText` 内部使用 `NoteSymbol` SVG 组件渲染升降号：

- `alter = 0` 且 `isNatural = false` → 不显示符号
- `alter = 0` 且 `isNatural = true` → 显示还原号 (♮)
- `alter = 1` → 显示升号 (#)
- `alter = -1` → 显示降号 (♭)
- `alter = 2` → 显示重升号 (×)
- `alter = -2` → 显示重降号 (𝄫)
