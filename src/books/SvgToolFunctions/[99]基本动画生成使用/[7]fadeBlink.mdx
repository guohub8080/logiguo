# {title}

`genAnimateSoftBlink` 是专门用于创建闪烁/淡入淡出效果的预设动画工具。闪烁动画是一种透明度循环变化的效果，常用于吸引注意力、加载状态、错误提示等场景。

---

## 函数签名

```tsx
import { genAnimateSoftBlink } from '@svg-anim/blink';

genAnimateSoftBlink({
  maxOpacity?: number,               // 默认 1：最大透明度（0-1）
  minOpacity?: number,               // 默认 0.2：最小透明度（0-1）
  onceBlinkDurationSeconds?: number, // 默认 1.2：一次闪烁时长（秒）
  keySplines?: string,               // 默认 '0.45 0 0.55 1'：缓动曲线
  repeatCount?: number,              // 默认 0：循环次数（0 = 无限）
  delay?: number,                    // 默认 0：初始延迟（秒）
  beginType?: SvgBeginEventType,        // 默认 undefined：动画开始事件类型
})
```

## 使用示例

### 简单的闪烁效果

```tsx
<svg width="200" height="200">
  <path
    d="M100 20 L120 80 L180 80 L130 120 L150 180 L100 140 L50 180 L70 120 L20 80 L80 80 Z"
    fill="yellow"
  >
    {genAnimateSoftBlink({
      maxOpacity: 1,
      minOpacity: 0.2,
      onceBlinkDurationSeconds: 1.2
    })}
  </path>
</svg>
```

**生成的 SVG 代码：**

```xml
<animate
  attributeName="opacity"
  values="1; 0.2; 1"
  dur="1.2s"
  repeatCount="indefinite"
  calcMode="spline"
  keySplines="0.45 0 0.55 1; 0.45 0 0.55 1"
/>
```

**效果**：星星在完全显示和半透明之间循环闪烁

## 预设效果

### softBlinkPresets

```tsx
import { softBlinkPresets } from '@svg-anim/blink';

// 轻柔淡入淡出
softBlinkPresets.gentle()

// 标准淡入淡出
softBlinkPresets.normal()

// 深度淡化
softBlinkPresets.deep()

// 快速闪烁
softBlinkPresets.fast()

// 慢速淡化
softBlinkPresets.slow()

// 微弱淡化
softBlinkPresets.subtle()

// 闪烁效果（完全消失）
softBlinkPresets.blink()
```

## 注意事项

### 透明度范围

- `maxOpacity` 和 `minOpacity` 都必须在 `0` 到 `1` 之间
- `maxOpacity` 应该大于 `minOpacity`

### 闪烁效果建议

- **快速闪烁**：适合用于提示、警告
- **慢速闪烁**：适合用于装饰、氛围
- **完全闪烁**（minOpacity: 0）：适合用于强提示
- **轻微闪烁**（minOpacity: 0.7-0.8）：适合用于装饰性元素
