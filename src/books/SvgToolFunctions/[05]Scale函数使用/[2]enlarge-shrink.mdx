export const title = "放大与缩小"

import { Enlarge, Shrink, Pulse, Bounce } from "./examples"

# {title}

缩放动画可以改变元素的大小，创建放大、缩小、脉冲等各种视觉效果。

---

## 放大动画

元素从原始大小放大到指定倍数。

**代码示例：**

```tsx
genAnimateScale({
  origin: [100, 100],
  timeline: [
    { toValue: 2, durationSeconds: 2 }
  ]
})
```

**效果预览：**

<Enlarge />

**说明**：蓝色方块从原始大小放大到 2 倍

---

## 缩小动画

元素从原始大小缩小到指定比例。

**代码示例：**

```tsx
genAnimateScale({
  origin: [100, 100],
  timeline: [
    { toValue: 0.5, durationSeconds: 2 }
  ]
})
```

**效果预览：**

<Shrink />

**说明**：绿色方块从原始大小缩小到 0.5 倍

---

## 脉冲缩放

元素快速放大后快速恢复，产生脉冲效果。

**代码示例：**

```tsx
genAnimateScale({
  origin: [100, 100],
  timeline: [
    { toValue: 1.5, durationSeconds: 0.5 },
    { toValue: 1, durationSeconds: 0.5 }
  ],
  loopCount: 0
})
```

**效果预览：**

<Pulse />

**说明**：紫色方块持续产生脉冲缩放效果

---

## 弹跳缩放

元素放大后弹回原始大小，产生弹跳效果。

**代码示例：**

```tsx
genAnimateScale({
  origin: [100, 100],
  timeline: [
    {
      toValue: 1.8,
      durationSeconds: 0.8,
      keySplines: '0.68 -0.55 0.265 1.55'  // 弹性曲线
    }
  ]
})
```

**效果预览：**

<Bounce />

**说明**：橙色方块有弹性地放大到 1.8 倍后弹回

---

## 使用辅助函数

`genAnimateScale` 提供了多个辅助函数，简化常见场景：

| 函数 | 说明 | 示例 |
|------|------|------|
| `genAnimateScaleSimple` | 简单缩放 | `genAnimateScaleSimple(2, 2)` |
| `genAnimateScaleLoop` | 往返缩放 | `genAnimateScaleLoop(0.8, 1.2, 1.5)` |
| `genAnimateScalePulse` | 脉冲缩放 | `genAnimateScalePulse(1.3, 0.5)` |
| `genAnimateScaleBounce` | 弹跳缩放 | `genAnimateScaleBounce(1.5, 1)` |
| `genAnimateScalePath` | 缩放序列 | `genAnimateScalePath([1, 1.2, 1.5, 1.2, 1])` |

---

## 总结

| 效果 | toValue | 使用场景 |
|------|---------|----------|
| 缩小到一半 | `0.5` | 消失效果、淡出 |
| 原始大小 | `1` | 默认值、正常状态 |
| 放大 1.2 倍 | `1.2` | 微妙强调 |
| 放大 1.5 倍 | `1.5` | 明显强调 |
| 放大 2 倍 | `2` | 重要强调 |
