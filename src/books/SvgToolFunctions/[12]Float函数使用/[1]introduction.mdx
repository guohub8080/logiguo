# {title}

`genAnimateFloat` 是专门用于创建浮动动画效果的预设动画工具。浮动动画是一种平滑的位移效果，让元素在指定方向上上下、左右或对角浮动，常用于营造悬浮感、漂浮感、轻盈感等视觉效果。

---

## 函数签名

```tsx
import { genAnimateFloat } from '@svg-anim/float';

genAnimateFloat({
  floatRangeY?: number,              // 默认 20：Y轴浮动范围（像素）
  floatRangeX?: number,              // 默认 0：X轴浮动范围（像素）
  durationSeconds?: number,          // 默认 4：动画时长（秒）
  keySplines?: string,               // 默认 '0.24 0 0.24 1'：缓动曲线
  repeatCount?: number,              // 默认 0：重复次数（0 = 无限）
  delay?: number,                    // 默认 0：初始延迟（秒）
  beginType?: SvgBeginEventType,     // 默认 undefined：动画开始事件类型
})
```

---

## 核心概念

### 什么是浮动动画？

浮动动画是一种平滑的位移动画，让元素在指定方向上来回移动：
- **起始位置**：元素的原始位置
- **移动阶段**：向相反方向移动（如上浮到下沉）
- **返回阶段**：回到起始位置
- **循环播放**：自动无限循环（可配置次数）

### 参数详解

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `floatRangeY` | `number` | `20` | Y轴浮动范围（像素）|
| `floatRangeX` | `number` | `0` | X轴浮动范围（像素）|
| `durationSeconds` | `number` | `4` | 单次浮动周期（秒）|
| `keySplines` | `string` | `'0.24 0 0.24 1'` | 缓动曲线 |
| `repeatCount` | `number` | `0` | 重复次数（0 = 无限）|
| `delay` | `number` | `0` | 初始延迟（秒）|
| `beginType` | `SvgBeginEventType` | `undefined` | 动画开始事件类型 |

## 基本用法

### 最简单的浮动效果

使用默认参数创建标准上下浮动效果。

**代码示例：**

```tsx
import { genAnimateFloat } from "@svg-anim/float";

<svg width="200" height="200" viewBox="0 0 200 200">
  <g>
    {genAnimateFloat({ floatRangeY: 20, durationSeconds: 4 })}
    <circle cx="100" cy="100" r="50" fill="blue" />
  </g>
</svg>
```

**效果预览：**

<BasicFloat />

**说明：** 蓝色圆形在垂直方向上下浮动，范围为 20 像素，周期为 4 秒。

## 注意事项

### 1. 浮动范围要适中

浮动范围过大会让元素移出可视区域：

**✅ 推荐：** `floatRangeY: 10-30`

**❌ 避免：** `floatRangeY: 100+`（可能导致元素完全移出视图）

---

### 2. 动画时长与浮动范围配合

- **小范围浮动**：使用较短时长（1.5-3秒）
- **大范围浮动**：使用较长时长（4-6秒）

这样可以让动画看起来更自然。

---

### 3. 与其他动画的组合

浮动动画可以与其他动画叠加使用：

```tsx
<g>
  {genAnimateFloat({ floatRangeY: 20, durationSeconds: 4 })}
  {genAnimateRotate({ additive: true })}
  <rect width="100" height="100" fill="red" />
</g>
```
