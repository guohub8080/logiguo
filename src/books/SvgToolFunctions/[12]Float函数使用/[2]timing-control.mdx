# {title}

`genAnimateFloat` 提供了丰富的时序控制选项，包括延迟启动、循环次数控制、点击触发等，让你能够精确控制浮动动画的时机和次数。

---

## 延迟启动

使用 `delay` 参数让动画在指定时间后自动开始。

### 基础延迟

**代码示例：**

```tsx
{genAnimateFloat({
  floatRangeY: 20,
  durationSeconds: 3,
  delay: 2  // 延迟 2 秒后开始
})}
```

**生成的 SVG 代码：**

```xml
<animateTransform
  attributeName="transform"
  type="translate"
  values="0 0;0 -20;0 0"
  dur="3s"
  begin="2s"
  repeatCount="indefinite"
  calcMode="spline"
  keySplines="0.24 0 0.24 1;0.24 0 0.24 1"
/>
```

**效果预览：**

<DelayFloat />

**说明：** 页面加载 2 秒后，圆形开始浮动。

---

## 循环次数控制

使用 `repeatCount` 参数控制动画重复次数。

### 有限次数循环

**代码示例：**

```tsx
{genAnimateFloat({
  floatRangeY: 20,
  durationSeconds: 2,
  repeatCount: 3  // 浮动 3 次后停止
})}
```

**生成的 SVG 代码：**

```xml
<animateTransform
  attributeName="transform"
  type="translate"
  values="0 0;0 -20;0 0"
  dur="2s"
  repeatCount="3"
  calcMode="spline"
  keySplines="0.24 0 0.24 1;0.24 0 0.24 1"
/>
```

**效果预览：**

<LimitedFloat />

**说明：** 圆形上下浮动 3 次后停止在初始位置。

---

### 只浮动一次

**代码示例：**

```tsx
{genAnimateFloat({
  floatRangeY: 30,
  durationSeconds: 4,
  repeatCount: 1  // 只浮动 1 次
})}
```

**效果预览：**

<OnceFloat />

**说明：** 圆形从起点向上浮动到顶点，再回到起点，然后停止。

---

### 无限循环

**代码示例：**

```tsx
{genAnimateFloat({
  floatRangeY: 15,
  durationSeconds: 1,
  repeatCount: 0  // 0 表示无限循环
})}
```

**效果预览：**

<InfiniteFastFloat />

**说明：** 圆形持续快速浮动，不会停止（默认行为）。

---

## 点击触发

使用 `beginType: 'click'` 参数让动画在点击时开始。

### 基础点击触发

**代码示例：**

```tsx
{genAnimateFloat({
  floatRangeY: 20,
  durationSeconds: 3,
  beginType: 'click'
})}
```

**生成的 SVG 代码：**

```xml
<animateTransform
  attributeName="transform"
  type="translate"
  values="0 0;0 -20;0 20;0 0"
  dur="3s"
  begin="click"
  repeatCount="indefinite"
  calcMode="spline"
  keySplines="0.24 0 0.24 1;0.24 0 0.24 1;0.24 0 0.24 1"
/>
```

**效果预览：**

<ClickFloat />

**说明：** 点击圆形后，开始无限循环浮动。

---

### 点击触发 + 延迟

**代码示例：**

```tsx
{genAnimateFloat({
  floatRangeY: 20,
  durationSeconds: 3,
  beginType: 'click',
  delay: 0.5  // 点击后延迟 0.5 秒开始
})}
```

**生成的 SVG 代码：**

```xml
<animateTransform
  attributeName="transform"
  type="translate"
  values="0 0;0 -20;0 20;0 0"
  dur="3s"
  begin="click+0.5s"
  repeatCount="indefinite"
  calcMode="spline"
  keySplines="0.24 0 0.24 1;0.24 0 0.24 1;0.24 0 0.24 1"
/>
```

**效果预览：**

<ClickDelayFloat />

**说明：** 点击圆形后，等待 0.5 秒，然后开始浮动。

## 时序控制最佳实践

### 场景 1：入场动画

**需求：** 元素入场后轻柔浮动，吸引注意但不打扰

**推荐参数：**

```tsx
{genAnimateFloat({
  floatRangeY: 10,
  durationSeconds: 4,
  delay: 0.5,
  repeatCount: 0
})}
```

**效果：** 延迟 0.5 秒后开始无限轻柔浮动

---

### 场景 2：点击反馈

**需求：** 点击后元素浮动几下，表示操作被接收

**推荐参数：**

```tsx
{genAnimateFloat({
  floatRangeY: 15,
  durationSeconds: 1.5,
  beginType: 'click',
  repeatCount: 3
})}
```

**效果：** 点击后快速浮动 3 次

---

### 场景 3：限时强调

**需求：** 页面加载后浮动 5 次引起注意，然后停止

**推荐参数：**

```tsx
{genAnimateFloat({
  floatRangeY: 25,
  durationSeconds: 2,
  repeatCount: 5
})}
```

**效果：** 浮动 5 次（共 10 秒）后停止

---

### 场景 4：持续装饰

**需求：** 装饰性元素持续缓慢浮动，营造氛围

**推荐参数：**

```tsx
{genAnimateFloat({
  floatRangeY: 8,
  floatRangeX: 5,
  durationSeconds: 6,
  repeatCount: 0
})}
```

**效果：** 无限缓慢对角浮动，非常轻柔

## 微信公众号注意事项

### 点击触发在微信中的应用

微信公众号对 `begin="click"` 有良好支持，常用于：

- **答案展示** - 点击后内容浮动出现
- **选项卡** - 点击后内容浮动切换
- **互动反馈** - 点击后按钮浮动确认

**完整示例：**

```tsx
<svg viewBox="0 0 200 200">
  <g style={{ cursor: 'pointer' }}>
    <rect width="200" height="200" fill="transparent" />
    <circle cx="100" cy="100" r="50" fill="blue">
      {genAnimateFloat({
        floatRangeY: 20,
        durationSeconds: 3,
        beginType: 'click',
        repeatCount: 3
      })}
    </circle>
  </g>
</svg>
```

---

## repeatCount 特殊值说明

| 值 | 效果 | 生成的 repeatCount 属性 |
|------|------|------------------------|
| `0` | 无限循环 | `indefinite` |
| `1` | 执行一次 | `1` |
| `3` | 执行三次 | `3` |
| `undefined` | 使用默认值 | `indefinite` |
