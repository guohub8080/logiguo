# {title}

图片推入式切换效果，新图片从指定方向推入，将旧图片推出画面。

## 核心特点

- ✅ 支持四个方向推入（L/R/T/B）
- ✅ 每张图片独立配置切换时长和停留时长
- ✅ 自定义贝塞尔曲线控制动画缓动
- ✅ 自动循环播放

---

## 原理说明

### 核心机制

`AnyPush` 基于 **SVG animateTransform** 实现图片推入效果：

1. **图片叠加**：所有图片通过 `<foreignObject>` 叠加在同一位置
2. **变换动画**：每张图片有独立的 `<animateTransform type="translate">` 控制位移
3. **方向推入**：新图片从指定方向（L/R/T/B）平移进入，旧图片被推出
4. **时间分段**：通过计算每张图的开始时间，实现依次推入的效果

### 动画时间线

每张图片的完整周期：

```
等待 → 推入(switchDuration) → 保持显示(stayDuration) → 被推出 → 等待
```

- **等待阶段**：图片在画布外等待（根据方向定位）
- **推入阶段**：图片从画布外平移进入画布中心
- **保持阶段**：图片完全显示在画布中心
- **被推出阶段**：下一张图推入时，当前图被推出画布

### 方向与初始位置

| 方向 | 初始位置 | 推入方向 |
|------|----------|----------|
| `L` (左) | `x = -viewBoxW` | 从左向右 |
| `R` (右) | `x = viewBoxW` | 从右向左 |
| `T` (上) | `y = -viewBoxH` | 从上向下 |
| `B` (下) | `y = viewBoxH` | 从下向上 |

### Values & KeyTimes 计算

假设有2张图片，每张 `switchDuration=0.5s, stayDuration=1s`：

**图片1（方向=R）**：
- 开始时间：0s
- 推入结束：0.5s
- 保持结束：1.5s
- 被推出：2s（图片2推入时）
- values: `viewBoxW; 0; 0; -viewBoxW`
- keyTimes: `0; 0.25; 0.75; 1`

**图片2（方向=R）**：
- 开始时间：1.5s（图片1保持结束）
- 推入结束：2s
- 保持结束：3s
- 被推出：3.5s（下一轮图片1推入时）
- values: `viewBoxW; 0; 0; -viewBoxW`
- keyTimes: `0; 0.125; 0.625; 1`（相对于2秒周期）

## 参数说明

### Props

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `pics` | `Array<PicConfig>` | 图片配置数组 | 见下方表 |
| `viewBoxW` | `number` | 画布宽度（可选） | `300` |
| `viewBoxH` | `number` | 画布高度（可选） | `300` |
| `mp` | `mpProps` | 边距样式 | `{ t: 0, r: 0, b: 0, l: 0 }` |

### PicConfig

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `url` | `string` | 必填 | 图片地址 |
| `direction` | `"L" \| "R" \| "T" \| "B"` | `"R"` | 推入方向 |
| `switchDuration` | `number` | `0.5` | 切换时长（秒） |
| `stayDuration` | `number` | `0.5` | 停留时长（秒） |
| `keySplines` | `string` | `"0.42 0 0.58 1"` | 贝塞尔曲线 |

## 使用示例

### 1. 基本示例

默认从右侧推入，使用默认缓动：

```tsx
import { AnyPush } from '@pub-svg/C3_MultiDisplay/AnyPush';

<AnyPush
    pics={[
        { url: pic1 },
        { url: pic2 },
        { url: pic3 },
    ]}
/>
```

### 2. 跑马灯效果

当所有图片使用相同的方向、相同的时长、停留时间为 0 和线性缓动时，可实现完全覆盖的跑马灯效果。

**跑马灯要点：**

- ✅ 所有图片使用相同的 `direction`
- ✅ 所有图片使用相同的 `switchDuration`
- ✅ `stayDuration` 设置为 `0`（无停留，连续播放）
- ✅ 使用 `getLinearBezier()` 线性缓动
- ✅ 效果：图片匀速连续推入，形成流畅的跑马灯

```tsx
import { getLinearBezier } from '@pub-utils/getBezier';

<AnyPush
    pics={[
        { url: pic1, direction: "R", switchDuration: 0.5, stayDuration: 0, keySplines: getLinearBezier() },
        { url: pic2, direction: "R", switchDuration: 0.5, stayDuration: 0, keySplines: getLinearBezier() },
        { url: pic3, direction: "R", switchDuration: 0.5, stayDuration: 0, keySplines: getLinearBezier() },
        { url: pic4, direction: "R", switchDuration: 0.5, stayDuration: 0, keySplines: getLinearBezier() },
        { url: pic5, direction: "R", switchDuration: 0.5, stayDuration: 0, keySplines: getLinearBezier() },
    ]}
/>
```

### 3. 综合应用

结合方向、时长、缓动函数的完整示例：

```tsx
import { getEaseBezier, getPowerBezier, getLinearBezier } from '@pub-utils/getBezier';

<AnyPush
    pics={[
        {
            url: pic1,
            direction: "R",
            switchDuration: 0.8,
            stayDuration: 1.2,
            keySplines: getEaseBezier({ isIn: true, isOut: true })
        },
        {
            url: pic2,
            direction: "B",
            switchDuration: 0.6,
            stayDuration: 1,
            keySplines: getPowerBezier({ power: 2, isIn: true, isOut: true })
        },
        {
            url: pic3,
            direction: "L",
            switchDuration: 0.7,
            stayDuration: 1.5,
            keySplines: getEaseBezier({ isIn: false, isOut: true })
        },
        {
            url: pic4,
            direction: "T",
            switchDuration: 0.5,
            stayDuration: 0.8,
            keySplines: getLinearBezier()
        },
        {
            url: pic5,
            direction: "R",
            switchDuration: 1,
            stayDuration: 1,
            keySplines: getPowerBezier({ power: 4, isIn: true, isOut: false })
        },
        {
            url: pic6,
            direction: "B",
            switchDuration: 0.4,
            stayDuration: 1.3,
            keySplines: getEaseBezier({ isIn: true, isOut: false })
        },
    ]}
/>
```

### 4. 田字格多画布组合

四个画布组成田字格布局，各自使用不同的方向、时长、图片数量和缓动函数：

```tsx
<div style={{ display: 'grid', gridTemplateColumns: 'repeat(2, 1fr)', gap: 0 }}>
    {/* 左上：3张图 */}
    <AnyPush pics={[
        { url: pic1, direction: "R", switchDuration: 0.5, ... },  // 右
        { url: pic2, direction: "B", switchDuration: 0.7, ... },  // 下
        { url: pic3, direction: "L", switchDuration: 0.4, ... }   // 左
    ]} />

    {/* 右上：4张图 */}
    <AnyPush pics={[
        { url: pic4, direction: "T", switchDuration: 0.6, ... },  // 上
        { url: pic5, direction: "R", switchDuration: 0.9, ... },  // 右
        { url: pic6, direction: "B", switchDuration: 0.5, ... },  // 下
        { url: pic1, direction: "L", switchDuration: 0.8, ... }   // 左
    ]} />

    {/* 左下：2张图 */}
    <AnyPush pics={[
        { url: pic2, direction: "T", switchDuration: 1.0, ... },  // 上
        { url: pic3, direction: "R", switchDuration: 0.4, ... }   // 右
    ]} />

    {/* 右下：5张图 */}
    <AnyPush pics={[
        { url: pic4, direction: "L", switchDuration: 0.3, ... },  // 左
        { url: pic5, direction: "T", switchDuration: 0.8, ... },  // 上
        { url: pic6, direction: "R", switchDuration: 0.6, ... },  // 右
        { url: pic1, direction: "B", switchDuration: 0.9, ... },  // 下
        { url: pic2, direction: "L", switchDuration: 0.5, ... }   // 左
    ]} />
</div>
```

## 使用技巧

### 💡 推荐实践

- **方向选择**：水平方向（L/R）适合风景图，垂直方向（T/B）适合人物图
- **时长设置**：切换时长 0.3-1 秒最佳，停留时长根据内容复杂度调整
- **缓动函数**：默认的 ease-in-out 适合大多数场景
- **跑马灯效果**：相同方向+相同时长+停留为0+线性缓动，可实现连续流畅的跑马灯
- **图片数量**：建议 3-6 张，过多会影响用户体验
- **图片尺寸**：确保所有图片尺寸一致，避免画面跳动
- **自动循环**：组件会自动循环播放，无需额外配置

### ⚠️ 注意事项

- 如果只提供 1 张图片，会自动复制为 2 张以实现动画效果
- 方向参数仅支持 `"L"`、`"R"`、`"T"`、`"B"` 四个值
- 图片会按照数组顺序依次播放
- 每张图片的切换时长和停留时长独立计算
