# {title}

理解倾斜方向是使用 Skew 函数的关键。本章详细说明 SkewX 和 SkewY 的方向规则。

---

## SkewX 方向详解

### 方向规则

**正值 = 向右倾斜**
- 顶部固定，底部向右移动
- 产生向右的平行四边形效果

**负值 = 向左倾斜**
- 顶部固定，底部向左移动
- 产生向左的平行四边形效果

### 可视化示例

```tsx
// 向右倾斜 30°
skewX(30°)
┌─────┐
│     ╱
│    ╱
│   ╱
│  ╱
└─┘

// 向左倾斜 -30°
skewX(-30°)
  ╲
 ╲ │
╲  │
 ╲ │
└─╲┘
```

**代码：**

```tsx

<SkewXDirection />
```

## SkewY 方向详解

### 方向规则

**正值 = 向下倾斜**
- 左侧固定，右侧向下移动
- 产生向下的平行四边形效果

**负值 = 向上倾斜**
- 左侧固定，右侧向上移动
- 产生向上的平行四边形效果

### 可视化示例

```tsx
// 向下倾斜 30°
skewY(30°)
┌─────╮
│     │╲
│     │ ╲
│     │  ╲
└─────┴───┘

// 向上倾斜 -30°
skewY(-30°)
    ╱
   ╱│
  ╱ │
 ╱  │
╱   │
└───┴───┘
```

## 角度参考表

### SkewX 水平倾斜

| 角度 | 效果 | 视觉描述 |
|------|------|----------|
| `-45°` | 向左大幅倾斜 | 强烈的向左倾斜感 |
| `-30°` | 向左倾斜 | 明显的向左倾斜 |
| `-15°` | 轻微向左倾斜 | 微妙的向左倾斜 |
| `0°` | 无倾斜 | 原始矩形 |
| `15°` | 轻微向右倾斜 | 微妙的向右倾斜 |
| `30°` | 向右倾斜 | 明显的向右倾斜 |
| `45°` | 向右大幅倾斜 | 强烈的向右倾斜感 |

| 角度 | 效果 | 视觉描述 |

## 常见误区

### 误区 1：混淆 SkewX 和 SkewY

**错误理解**：
- 认为 SkewX 控制垂直方向
- 认为 SkewY 控制水平方向

**正确理解**：
- **SkewX** = 沿 X 轴倾斜 = 水平倾斜
- **SkewY** = 沿 Y 轴倾斜 = 垂直倾斜

### 误区 2：方向判断错误

**记忆技巧**：
- **SkewX** → X 轴是水平的 → 左右倾斜
- **SkewY** → Y 轴是垂直的 → 上下倾斜

## 实用技巧

### 创建对称动画

结合正负角度，创建对称的摇摆效果：

```tsx
// 摇摆动画
genAnimateSkewX({
  timeline: [
    { toValue: 15, durationSeconds: 0.5 },
    { toValue: -15, durationSeconds: 1 },
    { toValue: 15, durationSeconds: 1 }
  ],
  loopCount: 0
})
```

### 极端角度效果

使用大角度（45°+）创造夸张的视觉效果：

```tsx
// 极端倾斜
genAnimateSkewY({
  timeline: [
    { toValue: 60, durationSeconds: 2 }
  ]
})
```
