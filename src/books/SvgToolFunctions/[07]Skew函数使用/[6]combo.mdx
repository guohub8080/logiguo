# {title}

Skew 变换可以与 Rotate、Scale、Translate 等其他变换组合使用，创造复杂的动画效果。

---

## 变换叠加顺序

在 SVG 中，多个变换会按照声明顺序**从右到左**依次应用：

```tsx
<g>
  {genAnimateSkewX({...})}
  {genAnimateScale({...})}
  {genAnimateRotate({...})}
</g>
```

**应用顺序**：
1. 先应用 Rotate（旋转）
2. 再应用 Scale（缩放）
3. 最后应用 SkewX（倾斜）

## Skew + Scale 组合

### 倾斜缩放效果

**代码示例：**

```tsx
import { genAnimateSkewX } from "@svg-anim/skewX";
import { genAnimateScale } from "@svg-anim/scale";

<svg width="100%" height="160" viewBox="0 0 280 160">
  <g transform="translate(140, 80)">
    <rect x="-60" y="-40" width="120" height="80" fill="rgb(59, 130, 246)" rx="8">
      {genAnimateSkewX({
        timeline: [
          { toValue: 12, durationSeconds: 1.5 },
          { toValue: -12, durationSeconds: 3 },
          { toValue: 12, durationSeconds: 1.5 }
        ],
        loopCount: 0,
        additive: true
      })}
      {genAnimateScale({
        timeline: [
          { toValue: 1.3, durationSeconds: 1.5 },
          { toValue: 0.7, durationSeconds: 3 },
          { toValue: 1.3, durationSeconds: 1.5 }
        ],
        loopCount: 0,
        additive: true
      })}
    </rect>
  </g>
</svg>
```

**效果：**

**说明**：方块在倾斜的同时进行缩放，产生透视变化效果

## 完整变换组合

### Skew + Scale + Rotate + Translate

**代码示例：**

```tsx
import { genAnimateSkewY } from "@svg-anim/skewY";
import { genAnimateScale } from "@svg-anim/scale";
import { genAnimateRotate } from "@svg-anim/rotate";
import { genAnimateTranslate } from "@svg-anim/translate";

<svg width="100%" height="200" viewBox="0 0 280 200">
  <g transform="translate(140, 100)">
    {genAnimateSkewY({
      timeline: [
        { toValue: 10, durationSeconds: 2 },
        { toValue: -10, durationSeconds: 2 }
      ],
      loopCount: 0,
      additive: true
    })}
    {genAnimateScale({
      timeline: [
        { toValue: { x: 1.15, y: 0.85 }, durationSeconds: 2 },
        { toValue: { x: 0.85, y: 1.15 }, durationSeconds: 2 }
      ],
      loopCount: 0,
      additive: true
    })}
    {genAnimateRotate({
      timeline: [
        { toValue: 180, durationSeconds: 4 }
      ],
      loopCount: 0,
      additive: true
    })}
    {genAnimateTranslate({
      timeline: [
        { toValue: { x: 12, y: 0 }, durationSeconds: 2 },
        { toValue: { x: -12, y: 0 }, durationSeconds: 2 }
      ],
      loopCount: 0,
      additive: true
    })}
    <rect x="-60" y="-60" width="120" height="120" fill="rgb(168, 85, 247)" rx="8" />
  </g>
</svg>
```

**效果：**

<FullTransformCombo />

**说明**：组合所有变换，创造复杂的多轴运动效果

## additive 累加模式

### 理解 additive 参数

`additive: true` 表示变换在**当前状态基础上累加**：

```tsx
genAnimateSkewX({
  additive: true,  // 在当前倾斜角度上累加
  timeline: [
    { toValue: 20, durationSeconds: 1 }
  ]
})
```

**效果：**
- 如果当前是 10°，则倾斜到 10° + 20° = 30°
- 而不是直接设置到 20°

### 多变换累加示例

```tsx
<g>
  {/* 旋转动画 */}
  {genAnimateRotate({
    timeline: [
      { toValue: 360, durationSeconds: 4 }
    ],
    additive: true,
    loopCount: 0
  })}

  {/* 倾斜动画（累加到旋转状态） */}
  {genAnimateSkewX({
    timeline: [
      { toValue: 30, durationSeconds: 1 },
      { toValue: 0, durationSeconds: 1 },
      { toValue: -30, durationSeconds: 1 },
      { toValue: 0, durationSeconds: 1 }
    ],
    additive: true,
    loopCount: 0
  })}

  {/* 缩放动画（累加到旋转+倾斜状态） */}
  {genAnimateScale({
    timeline: [
      { toValue: { x: 0.5, y: 0.5 }, durationSeconds: 2 },
      { toValue: { x: 1, y: 1 }, durationSeconds: 2 }
    ],
    additive: true,
    loopCount: 0
  })}
</g>
```

**时间线分析：**

```
时间轴：
0s ─────── 2s ─────── 4s ─────── 6s ─────── 8s
旋转：   0° → 180°    → 360°   → 540°   → 720°
倾斜：   0° → 30°     → 0°     → -30°   → 0°
缩放：   1 → 0.5      → 1      → 0.5    → 1
```

## 实用组合模式

### 1. 3D 卡片翻转

```tsx
// Y 轴倾斜 + 旋转模拟卡片翻转
{genAnimateSkewY({
  timeline: [
    { toValue: 45, durationSeconds: 0.5 },    // 倾斜45度
    { toValue: -45, durationSeconds: 1 },   // 反向倾斜
    { toValue: 45, durationSeconds: 1 },    // 循环
    { toValue: 0, durationSeconds: 0.5 }     // 恢复
  ],
  loopCount: 0,
  additive: true
})}
{genAnimateScale({
  timeline: [
    { toValue: { x: 0.8, y: 1 }, durationSeconds: 0.5 },   // 水平压缩
    { toValue: { x: 0.8, y: 1 }, durationSeconds: 1 },
    { toValue: { x: 0.8, y: 1 }, durationSeconds: 1 },
    { toValue: { x: 1, y: 1 }, durationSeconds: 0.5 }
  ],
  loopCount: 0,
  additive: true
})}
```

### 2. 弹性摇摆

```tsx
// SkewX + ScaleY 模拟弹性
{genAnimateSkewX({
  timeline: [
    { toValue: 25, durationSeconds: 0.3 },
    { toValue: -20, durationSeconds: 0.6, keySplines: "0.42 0 0.58 1" },
    { toValue: 20, durationSeconds: 0.6, keySplines: "0.42 0 0.58 1" },
    { toValue: 0, durationSeconds: 0.3 }
  ],
  loopCount: 0
})}
{genAnimateScale({
  timeline: [
    { toValue: { x: 1, y: 1.1 }, durationSeconds: 0.3 },      // 拉伸
    { toValue: { x: 1, y: 1 }, durationSeconds: 0.6 },
    { toValue: { x: 1, y: 1.1 }, durationSeconds: 0.6 },
    { toValue: { x: 1, y: 1 }, durationSeconds: 0.3 }        // 恢复
  ],
  loopCount: 0,
  additive: true
})}
```

### 3. 入场动画

```tsx
// SkewY + Scale + Rotate 复杂入场
{genAnimateSkewY({
  timeline: [
    { toValue: 60, durationSeconds: 0.5 },    // 极度倾斜
    { toValue: 0, durationSeconds: 0.3 }     // 恢复
  ],
  additive: true
})}
{genAnimateScale({
  timeline: [
    { toValue: { x: 0, y: 0 }, durationSeconds: 0.5 },  // 缩小到0
    { toValue: { x: 1, y: 1 }, durationSeconds: 0.3 }     // 恢复
  ],
  additive: true
})}
{genAnimateRotate({
  timeline: [
    { toValue: 180, durationSeconds: 0.8 },   // 旋转180度
  ],
  additive: true
})}
```

## 注意事项

### 1. 变换顺序

不同的声明顺序会产生不同的效果：

```tsx
// 方案 A：先旋转再倾斜
{genAnimateRotate({...})}
{genAnimateSkewX({...})}

// 方案 B：先倾斜再旋转
{genAnimateSkewX({...})}
{genAnimateRotate({...})}

// 结果：方案 A ≠ 方案 B
```

### 2. additive 设置

- 所有变换都应设置 `additive: true` 确保正确叠加
- 如果某个变换设置为 `additive: false`，会打断累加链

### 3. 时间线同步

组合多个变换时，确保时间线协调：

```tsx
// 好的实践：时间对齐
{genAnimateSkewX({
  timeline: [
    { toValue: 30, durationSeconds: 2 },
    { toValue: 0, durationSeconds: 2 }
  ]
})}
{genAnimateScale({
  timeline: [
    { toValue: 1.5, durationSeconds: 2 },     // 同时进行
    { toValue: 1, durationSeconds: 2 }        // 同时恢复
  ]
}}
```
