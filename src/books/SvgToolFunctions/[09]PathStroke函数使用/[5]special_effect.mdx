除了基础的绘制和擦除效果，SVG 路径描边动画还可以实现更多特殊效果。本章节介绍两种实用效果：**蚂蚁线（流动虚线）** 和 **划线消失**。

---

## 蚂蚁线效果

蚂蚁线（Marching Ants）是一种虚线沿路径"流动"的动画效果，常用于：
- 选中框的边界动画
- 数据流动的可视化
- 进度指示
- 引导用户关注

### 原理说明

蚂蚁线使用两个核心属性：

**stroke-dasharray** - 定义虚线模式：

```
格式: "实线长度 间隔长度"

例如:
"10 10" → 10px实线，10px间隔
"5 5"   → 5px实线，5px间隔（更密集）
"20 10" → 20px实线，10px间隔（更长实线）
```

**stroke-dashoffset** - 虚线偏移量，通过动画改变此值实现"流动"：

```
关键公式:
offset 的变化范围 = stroke-dasharray 的总和

例如 stroke-dasharray="10 10":
总和 = 10 + 10 = 20
offset 从 20 → 0（或 0 → 20）
```

---

### 基础蚂蚁线

最简单的蚂蚁线效果，虚线沿直线流动。

**代码示例：**

```tsx
<svg width="400" height="100" viewBox="0 0 400 100">
  <path
    d="M 30 60 L 370 60"
    stroke="#3b82f6"
    strokeWidth="3"
    strokeDasharray="10 10"
    fill="none"
  >
    <animate
      attributeName="stroke-dashoffset"
      from="20"
      to="0"
      dur="0.5s"
      repeatCount="indefinite"
    />
  </path>
</svg>
```

**效果预览：**

<MarchingAnts />

**关键参数：**
- `strokeDasharray="10 10"` - 10px实线+10px间隔
- `from="20"` to `"0"` - 20 = 10+10（dasharray总和）
- `dur="0.5s"` - 0.5秒完成一次循环
- `repeatCount="indefinite"` - 无限重复

### 蚂蚁线配置技巧

#### 技巧1：调整流动方向

改变 `from` 和 `to` 的值可以反向流动：

```tsx
// 正向流动（从左到右）
<animate attributeName="stroke-dashoffset" from="20" to="0" ... />

// 反向流动（从右到左）
<animate attributeName="stroke-dashoffset" from="0" to="20" ... />
```

---

#### 技巧2：调整虚线样式

改变 `stroke-dasharray` 的值创造不同风格：

```tsx
// 点状虚线
strokeDasharray="2 5"

// 长划线
strokeDasharray="30 10"

// 点划线组合（需要多个值）
strokeDasharray="20 5 5 5"  // 长划20，间隔5，点5，间隔5
```

---

#### 技巧3：调整流动速度

改变 `dur`（持续时间）的值：

```tsx
// 快速流动
dur="0.2s"

// 中速流动
dur="0.5s"

// 慢速流动
dur="1s"
```

## 划线消失效果

划线消失是指路径绘制完成后，从某个位置开始逐渐消失的效果。

### 实现原理

**问题：** `stroke-dashoffset` 控制整条路径的显示状态，无法让路径的不同部分有不同的显示状态。

**解决方案：** 将路径分成多段，通过 `delay` 参数控制每段的开始时间，实现"逐渐消失"的视觉效果。

---

### 从中间向两边消失

将路径分成左右两半，右半段延迟开始擦除。

**代码示例：**

```tsx
<svg width="400" height="100" viewBox="0 0 400 100">
  {/* 左半段 */}
  {genAnimatePathStroke({
    pathLength: 170,
    initOffset: 0,
    timeline: [
      { durationSeconds: 2, toValue: 170 }
    ],
    element: (
      <line x1="30" y1="60" x2="200" y2="60" stroke="#ef4444" strokeWidth="3" strokeLinecap="round" />
    )
  })}

  {/* 右半段 - 延迟0.5秒后开始擦除 */}
  {genAnimatePathStroke({
    pathLength: 170,
    initOffset: 0,
    delay: 0.5,
    timeline: [
      { durationSeconds: 2, toValue: 170 }
    ],
    element: (
      <line x1="200" y1="60" x2="370" y2="60" stroke="#ef4444" strokeWidth="3" strokeLinecap="round" />
    )
  })}
</svg>
```

**效果预览：**

<EraseFromCenter />

**说明：**
- 总路径长度：340px，分成两段各170px
- 左半段立即开始擦除
- 右半段延迟0.5秒后开始擦除
- 视觉效果：从中间向两边逐渐消失

---

### 更多消失模式

#### 模式1：从左向右消失

```tsx
// 分成3段，依次延迟
pathLength: 100

// 第1段：立即擦除
{genAnimatePathStroke({ delay: 0, timeline: [{ toValue: 100 }] }, ...)}

// 第2段：延迟0.5秒
{genAnimatePathStroke({ delay: 0.5, timeline: [{ toValue: 100 }] }, ...)}

// 第3段：延迟1秒
{genAnimatePathStroke({ delay: 1, timeline: [{ toValue: 100 }] }, ...)}
```

---

#### 模式2：从两端向中间消失

```tsx
// 将路径分成多段，两端的段先擦除，中间的段后擦除
// 第1段（最左）
{genAnimatePathStroke({ delay: 0, ... })}

// 第2段（中间）
{genAnimatePathStroke({ delay: 1, ... })}  // 延迟更长

// 第3段（最右）
{genAnimatePathStroke({ delay: 0, ... })}
```

## 微信公众号兼容性

⚠️ **重要提示：** 微信公众号对 SVG 动画有限制

### 支持的功能

✅ **SMIL 动画标签**：
- `<animate>` - 属性动画
- `<set>` - 设置属性值

✅ **动画属性**：
- `attributeName` - 要动画的属性名
- `from` / `to` - 起始/结束值
- `dur` - 持续时间
- `repeatCount` - 重复次数

### 不支持的功能

❌ **CSS @keyframes 动画**
❌ **JavaScript 动画**
❌ **外部 CSS 文件**

### 兼容示例

```tsx
// ✅ 微信公众号兼容
<path strokeDasharray="10 10">
  <animate
    attributeName="stroke-dashoffset"
    from="20"
    to="0"
    dur="0.5s"
    repeatCount="indefinite"
  />
</path>

// ❌ 微信公众号不兼容（CSS动画）
<path
  strokeDasharray="10 10"
  style={{
    animation: "dash 0.5s linear infinite"
  }}
/>
```

## 效果对比速查表

| 效果 | 适用场景 | 核心属性 |
|------|----------|----------|
| **绘制动画** | 手绘效果、文字显现 | `stroke-dasharray: pathLength`, `stroke-dashoffset` 动画 |
| **蚂蚁线** | 进度指示、数据流动 | `stroke-dasharray: "实线 间隔"`, `offset` 循环 |
| **划线消失** | 擦除效果、转场 | 分段路径 + `delay` |
| **走走停停** | 教程演示、分步说明 | timeline 中 `toValue` 相邻相同 |

---

## 总结

1. **蚂蚁线**使用 `stroke-dasharray` 定义虚线，`stroke-dashoffset` 动画实现流动
2. **划线消失**通过分段路径 + delay 实现，无法用单一路径实现
3. **offset 变化范围**应等于 `stroke-dasharray` 的总和
4. **微信公众号**只支持 SMIL 动画（`<animate>`），不支持 CSS 动画
