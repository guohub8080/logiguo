# {title}

`isRelativeRotate` 参数控制角度的计算方式，有两种模式：相对旋转（增量）和绝对旋转。理解这个参数对于创建复杂的旋转动画至关重要。

---

## 相对旋转模式（isRelativeRotate: true，默认值）

每个阶段的 `toValue` 是**相对于上一阶段终点**的增量角度。

### 工作原理

```
当前角度 = 上一阶段角度 + toValue
```

**示例：**

```tsx
genAnimateRotate({
  initAngle: 0,
  isRelativeRotate: true,  // 默认值
  timeline: [
    { toValue: 90, durationSeconds: 1 },    // 0 + 90 = 90°
    { toValue: 0, durationSeconds: 1 },     // 90 + 0 = 90°（保持）
    { toValue: 90, durationSeconds: 1 }     // 90 + 90 = 180°
  ]
})
```

### 效果预览

<RelativeMode />

**说明**：0° → 90° → 保持不动 → 再转 90° 到 180°

---

## 绝对旋转模式（isRelativeRotate: false）

每个阶段的 `toValue` 是**相对于初始位置**的绝对角度。

### 工作原理

```
当前角度 = toValue（绝对坐标）
```

**示例：**

```tsx
genAnimateRotate({
  initAngle: 0,
  isRelativeRotate: false,
  timeline: [
    { toValue: 90, durationSeconds: 1 },    // 旋转到 90°
    { toValue: 90, durationSeconds: 1 },    // 保持在 90°
    { toValue: 180, durationSeconds: 1 }    // 旋转到 180°
  ]
})
```

### 效果预览

<AbsoluteMode />

**说明**：0° → 90° → 保持 90° → 180°

---

## 两种模式对比

虽然两个示例最终效果相同，但参数写法不同：

| 阶段 | 相对模式 `toValue` | 实际角度 | 绝对模式 `toValue` |
|------|-------------------|---------|-------------------|
| 初始 | - | 0° | - |
| 第1段 | `90` | 0° + 90° = **90°** | `90` → **90°** |
| 第2段 | `0` | 90° + 0° = **90°** | `90` → **90°** |
| 第3段 | `90` | 90° + 90° = **180°** | `180` → **180°** |

## 关键区别

### 相对模式（推荐）

```tsx
// ✅ 保持不动很简单
{ toValue: 0 }  // 相对于上一阶段，增量是 0
```

### 绝对模式

```tsx
// ❌ 保持不动需要重复上一个角度
{ toValue: 90 }  // 必须写绝对角度 90
```

## 使用场景

### 场景 1：单次旋转

两种模式都可以，推荐相对模式（默认）：

```tsx
genAnimateRotate({
  timeline: [
    { toValue: 360, durationSeconds: 2 }
  ]
})
```

### 场景 2：往返摆动

相对模式更直观：

```tsx
genAnimateRotate({
  initAngle: -30,
  timeline: [
    { toValue: 60, durationSeconds: 1 },    // -30 + 60 = 30°
    { toValue: -60, durationSeconds: 1 }    // 30 + (-60) = -30°
  ],
  loopCount: 0
})
```

### 场景 3：复杂路径

相对模式更容易理解增量：

```tsx
genAnimateRotate({
  initAngle: 0,
  timeline: [
    { toValue: 45, durationSeconds: 1 },   // 向右转 45°
    { toValue: 0, durationSeconds: 1 },    // 返回 45°
    { toValue: -45, durationSeconds: 1 },  // 向左转 45°
    { toValue: 0, durationSeconds: 1 }     // 返回中心
  ]
})
```

---

## 总结

| 特性 | 相对模式 | 绝对模式 |
|------|---------|---------|
| **默认值** | ✅ `true` | `false` |
| **toValue 含义** | 增量角度 | 绝对角度 |
| **保持不动** | `{ toValue: 0 }` | 需重复上一角度 |
| **适用场景** | 大多数情况 | 需要精确控制绝对角度 |

**推荐**：使用相对模式（默认），更符合直觉，代码更简洁。
