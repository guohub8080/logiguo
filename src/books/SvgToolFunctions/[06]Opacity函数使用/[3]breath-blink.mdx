# {title}

呼吸和闪烁是基于循环透明度的常见动画效果。本文介绍如何创建这些循环动画。

---

## 呼吸效果（Breathe）

呼吸效果是指元素在两个透明度之间平滑循环变化，类似呼吸的节奏。

### 基本用法

**代码示例：**

```tsx
import { genAnimateOpacity } from "@svg-anim/opacity";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="blue">
    {genAnimateOpacity({
      timeline: [
        { toValue: 0.3, durationSeconds: 2 },  // 淡出到 30%
        { toValue: 1, durationSeconds: 2 }     // 淡入回 100%
      ],
      loopCount: 0  // 无限循环
    })}
  </circle>
</svg>
```

**效果预览：**

<Breathe />

**说明**：圆形在 30% 和 100% 透明度之间循环

### 使用预设

```tsx
import { opacityPresets } from '@svg-anim/opacity';

// 呼吸效果（默认最低30%，单程2秒）
opacityPresets.breathe()

// 自定义参数（最低20%，单程3秒）
opacityPresets.breathe(0.2, 3)
```

## 闪烁效果（Blink）

闪烁效果是指元素快速地在透明和不透明之间切换。

### 基本用法

**代码示例：**

```tsx
import { genAnimateOpacity } from "@svg-anim/opacity";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="blue">
    {genAnimateOpacity({
      timeline: [
        { toValue: 0, durationSeconds: 0.5 },  // 0.5秒淡出
        { toValue: 1, durationSeconds: 0.5 }    // 0.5秒淡入
      ],
      loopCount: 0  // 无限循环
    })}
  </circle>
</svg>
```

**效果预览：**

<Blink />

**说明**：圆形每秒闪烁一次

### 使用预设

```tsx
import { opacityPresets } from '@svg-anim/opacity';

// 闪烁效果（默认3次闪烁，总时长1.5秒）
opacityPresets.blink()

// 自定义参数（5次闪烁，总时长2秒）
opacityPresets.blink(5, 2)

// 慢闪烁（较慢的明暗循环）
opacityPresets.slowBlink(2)
```

## 心跳效果（Heartbeat）

心跳效果模拟心脏跳动的节奏：快速连续两次跳动后停顿。

**代码示例：**

```tsx
import { genAnimateOpacity } from "@svg-anim/opacity";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="red">
    {genAnimateOpacity({
      timeline: [
        { toValue: 0.6, durationSeconds: 0.2 },  // 第一次跳动
        { toValue: 1, durationSeconds: 0.2 },
        { toValue: 0.6, durationSeconds: 0.2 },  // 第二次跳动
        { toValue: 1, durationSeconds: 0.2 },
        { durationSeconds: 0.8 }                 // 停顿
      ],
      loopCount: 0
    })}
  </circle>
</svg>
```

**效果预览：**

<Heartbeat />

**说明**：红色圆形模拟心跳节奏

## 幽灵效果（Ghost）

幽灵效果是元素在半透明和不透明之间缓慢循环，营造飘渺的感觉。

**代码示例：**

```tsx
import { genAnimateOpacity } from "@svg-anim/opacity";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="purple">
    {genAnimateOpacity({
      timeline: [
        { toValue: 0.5, durationSeconds: 1.5 },  // 半透明
        { toValue: 1, durationSeconds: 1.5 }     // 不透明
      ],
      loopCount: 0
    })}
  </circle>
</svg>
```

**效果预览：**

<Ghost />

**说明**：紫色圆形营造幽灵飘渺效果

### 使用预设

```tsx
import { opacityPresets } from '@svg-anim/opacity';

// 幽灵效果（默认单程1.5秒）
opacityPresets.ghost()

// 自定义时长
opacityPresets.ghost(3)
```

## 效果对比

| 效果 | 透明度范围 | 单程时长 | 节奏 |
|------|-----------|---------|------|
| 呼吸 | 30% - 100% | 2秒 | 平滑 |
| 闪烁 | 0% - 100% | 0.5秒 | 快速 |
| 心跳 | 60% - 100% | 0.2秒 | 跳动 |
| 幽灵 | 50% - 100% | 1.5秒 | 缓慢 |

## 实用技巧

### 脉冲效果（快速呼吸）

```tsx
import { opacityPresets } from '@svg-anim/opacity';

opacityPresets.pulse(0.5)  // 0.5秒完成一次呼吸
```

### 波浪渐变（多段过渡）

```tsx
import { opacityPresets } from '@svg-anim/opacity';

opacityPresets.wave(4)  // 4秒完成多段波浪渐变
```

### 淡入停留淡出循环

```tsx
import { opacityPresets } from '@svg-anim/opacity';

opacityPresets.fadeInOutCycle(1, 2, 1)
// 淡入1秒 -> 停留2秒 -> 淡出1秒
```
