# {title}

`genAnimateBreathe` 是专门用于创建呼吸动画效果的预设动画工具。呼吸动画是一种自动循环的缩放效果，模拟生物呼吸的节奏，常用于吸引注意力、提示重要信息、营造氛围等场景。

---

## 函数签名

```tsx
import { genAnimateBreathe } from '@svg-anim/breathe';

genAnimateBreathe({
  fromScale?: number,                    // 默认 1：初始缩放比例
  toScale?: number,                       // 默认 1.1：目标缩放比例
  onceBreatheDurationSeconds?: number,    // 默认 2：一次呼吸时长（秒）
  keySplines?: string | string[],         // 默认 '0.42 0 0.58 1'：缓动曲线
  repeatCount?: number,                   // 默认 0：循环次数（0 = 无限）
  delay?: number,                         // 默认 0：初始延迟（秒）
  transformOrigin?: string,               // 默认 'center'：变换原点
  additive?: boolean,                     // 默认 true：是否累加变换
  beginType?: SvgBeginEventType,         // 默认 undefined：动画开始事件类型
})
```

---

## 核心概念

### 什么是呼吸动画？

呼吸动画是一种平滑的缩放动画，模拟生物呼吸的节奏：
- **放大阶段**：从 `fromScale` 增大到 `toScale`
- **缩小阶段**：从 `toScale` 回到 `fromScale`
- **循环播放**：自动无限循环（可配置次数）

### 参数详解

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `fromScale` | `number` | `1` | 初始缩放比例 |
| `toScale` | `number` | `1.1` | 目标缩放比例 |
| `onceBreatheDurationSeconds` | `number` | `2` | 一次呼吸时长（秒）|
| `keySplines` | `string \| string[]` | `'0.42 0 0.58 1'` | 缓动曲线 |
| `repeatCount` | `number` | `0` | 重复次数（0 = 无限）|
| `delay` | `number` | `0` | 初始延迟（秒）|
| `transformOrigin` | `string` | `'center'` | 变换原点 |
| `additive` | `boolean` | `true` | 是否累加变换 |
| `beginType` | `SvgBeginEventType` | `undefined` | 动画开始事件类型 |

## 基本用法

### 最简单的呼吸效果

使用默认参数创建标准呼吸效果。

**代码示例：**

```tsx
import { genAnimateBreathe } from "@svg-anim/breathe";

<svg width="200" height="200" viewBox="0 0 200 200">
  <g style={{ transformOrigin: 'center', transformBox: 'fill-box' }}>
    {genAnimateBreathe()}
    <circle cx="100" cy="100" r="50" fill="blue" />
  </g>
</svg>
```

**效果预览：**

<BasicBreathe />

**说明：** 蓝色圆形在 1.0 和 1.1 倍大小之间循环呼吸，周期为 2 秒。

## 预设效果

## transformOrigin 设置

呼吸动画需要配合 `transformOrigin` 使用，否则缩放不会以元素中心为原点。

### 使用 centerBreatheStyle 常量

推荐直接导入并使用 `centerBreatheStyle` 常量：

```tsx
import { genAnimateBreathe, centerBreatheStyle } from '@svg-anim/breathe';

<svg width="200" height="200" viewBox="0 0 200 200">
  <g style={centerBreatheStyle}>
    {genAnimateBreathe()}
    <circle cx="100" cy="100" r="50" fill="blue" />
  </g>
</svg>
```

**centerBreatheStyle 包含的样式：**

```tsx
{
  transformOrigin: 'center',
  transformBox: 'fill-box'
}
```

### transformOrigin 取值说明

| 值 | 说明 | 推荐度 |
|------|------|--------|
| `'center'` | 以元素中心为原点 | ⭐⭐⭐⭐⭐ |
| `'origin'` | 以坐标原点 (0,0) 为原点 | ⭐⭐ |
| `'50% 50%'` | 自定义：元素中心 | ⭐⭐⭐⭐ |
| `'100 100'` | 自定义：指定坐标点 | ⭐⭐⭐ |

---

## 注意事项

### 1. 必须设置 transformOrigin

呼吸动画必须配合 `transformOrigin` 使用，否则缩放可能不符合预期。

**✅ 正确：**

```tsx
<g style={{ transformOrigin: 'center', transformBox: 'fill-box' }}>
  {genAnimateBreathe()}
  <circle cx="100" cy="100" r="50" fill="blue" />
</g>
```

**❌ 错误：**

```tsx
<g>
  {genAnimateBreathe()}
  <circle cx="100" cy="100" r="50" fill="blue" />
</g>
```

---

### 2. additive 参数的使用

`additive` 参数控制是否与其他动画叠加：

```tsx
// additive: true（默认）- 与其他动画叠加
<g>
  {genAnimateBreathe({ additive: true })}
  {genAnimateRotate({ additive: true })}
  <rect width="100" height="100" fill="red" />
</g>

// additive: false - 替换其他动画
<g>
  {genAnimateBreathe({ additive: false })}
  <rect width="100" height="100" fill="red" />
</g>
```

---

### 3. 呼吸效果建议

- **装饰元素**：使用小幅度（1.05-1.08）+ 慢速（2-3秒）
- **提示信息**：使用中幅度（1.1-1.15）+ 中速（1.5-2秒）
- **重要强调**：使用大幅度（1.2）+ 快速（1秒）
